# 우리동네이야기 화면 초안

`index.html`을 브라우저에서 엽니다. 인터넷 연결·설치가 필요하지 않습니다.

- 상단 선택기로 인증 시민·로그아웃·인증 만료·위임 직원 화면을 확인합니다.
- 지역 이름을 눌러 서울·마포구·성산1동 등을 탐색합니다.
- 글에서 ‘이야기 보기’와 ‘이어진 답글 보기’를 눌러 대화를 엽니다.
- ‘이야기 쓰기’에서 본문·사진·링크·요청 대표자를 선택합니다.
- 입력 내용은 이 화면의 메모리에만 보관되며 새로고침하면 초기화됩니다.

정책 기준: `../product-decisions.md`. 검토 범위와 제한: `../docs/screen-draft.md`.
