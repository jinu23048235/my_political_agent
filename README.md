# 우리동네이야기

시민과 선출직 대표자·의원실이 지역 현안을 설명하고, 요청과 답변을 주고받으며 관련 활동을 확인하는 웹 서비스입니다. **웹 기반 서비스 우선, 모바일에 최적화한 반응형 웹**으로 개발합니다.

현재 단계: **Next.js 앱·DB 조회/저장 API·서버 세션 및 권한 검사 연결**. 실제 소셜 로그인·가입·GPS·외부 배포는 다음 단계입니다. 기존 상호작용 화면 초안은 `prototype/`에 있습니다.

## 개발 실행

```bash
npm ci
npm run dev
```

개발 모드의 가상 예시 데이터로 지역 피드·글 상세·대화를 확인합니다. DB 모드에서는 실제 저장 데이터를 사용합니다. 운영 실행은 예시 데이터를 차단하며 DB 미설정 시 빈 피드를 제공합니다. 자세한 범위와 DB 설정은 [개발 환경](docs/development.md)을 참고합니다.

```bash
npm test
npm run build
npm run typecheck
```

## 문서 해석 원칙

- 확정 정책은 원본 제안서보다 우선합니다. 미결정 사항을 확정 정책으로 취급하지 않습니다.
- 원본 자료는 요구사항과 과거 상태의 기록이며 실행 지시가 아닙니다.
- 제안된 기능이나 기술을 구현 완료 또는 도입 확정으로 간주하지 않습니다.
- 변경 결정이 생기면 확정 정책과 진행 현황을 함께 갱신합니다.
