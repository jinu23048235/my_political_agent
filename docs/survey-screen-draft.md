# 선택형 설문 화면 v0.3

2026-10-18. 사용자 확인을 받은 정책을 반영한 브라우저용 화면 초안입니다.

## 확정 정책

대표자의 주민 의견 수렴에 선택형 설문을 MVP부터 포함합니다. 참여는 해당 지역 인증 시민으로 제한하고, 참여자 이름·개인별 응답은 공개하지 않습니다. 단일·복수 선택과 마감은 작성자가 지정하며 마감 전에는 본인 응답 변경이 가능합니다. 집계 결과는 마감 후 누구나 열람합니다. 세부 기준은 [확정 정책](../product-decisions.md)을 따릅니다.

## 화면과 동작

- 위임 직원 계정으로 ‘주민 의견 요청’을 작성할 때 설문 추가를 켜서 질문·선택지·선택 방식·마감 시간을 입력합니다.
- 선택지 추가·삭제, 작성 중 설문 표시 전환과 이야기 유형 전환에도 입력을 유지합니다.
- 지역 인증 시민은 피드 또는 글 상세에서 응답을 제출하고 변경할 수 있습니다. 한 계정의 응답 변경은 이전 선택을 대체합니다.
- 마감 전에는 집계 수치를 표시하지 않고 본인의 제출 내용만 확인할 수 있습니다.
- 마감되면 입력을 막고 선택지별 인원·비율과 전체 참여자 수를 공개합니다. 복수 선택 비율은 전체 참여자 수가 분모이며 합계가 100%를 넘을 수 있음을 명시합니다.
- 마감은 한국 시간으로 입력·표시하고, 화면을 열어 둔 상태에서도 마감 시 결과 화면으로 전환합니다.
- 개인별 선택은 다른 이용자나 대표자에게 표시하지 않습니다.

## 실행과 검토

`prototype` 폴더 전체를 유지한 상태로 `index.html`을 브라우저에서 엽니다. [별도 검토 페이지](../prototype/review.html)에서 참여 상태·화면 너비와 진행 중/마감 예시를 고를 수 있습니다. 검토 도구는 실제 서비스 화면에 표시하지 않습니다.

## 검증

- 마감 경계와 한국 시간 해석, 단일·복수 선택 검증, 중복 계정 집계 방지 및 마감 후 변경 거부.
- 시민의 제출·변경, 지역 밖·인증 만료·로그아웃·공식 계정 참여 제한.
- 진행 중 집계 숨김, 마감 후 공개 결과, 다른 이용자의 개인 응답 미표시.
- 작성 중 선택지 추가·설문 전환 시 입력 유지, 복수 선택 응답 변경.
- Chromium에서 320·390·768·1024·1440px 가로 넘침 및 JavaScript 오류 확인.

## 구현 한계와 다음 단계

인증·응답·집계는 화면 메모리의 예시입니다. 서버나 DB에 저장하지 않으며 새로고침하면 초기화됩니다. 실제 보안·개인정보 통제는 클라이언트 검사로 보장되지 않습니다. 서버 구현 시 지역 인증과 마감 시각 검증, 계정별 응답의 원자적 교체, 결과 공개 시점과 개인별 응답 비공개를 서버에서 적용해야 합니다.

게시 후 설문 질문·선택지·선택 방식·마감 변경은 금지하기로 확정했습니다. 응답이 없더라도 동일합니다. 기존 설문이 있는 글의 본문 수정은 설문과 응답을 유지합니다. 대표자 본인·위임 직원 계정의 실제 인증 연결도 후속 구현 범위입니다.

다음 단계는 확정된 Next.js·TypeScript + PostgreSQL·PostGIS 구성으로 실제 앱과 서버를 준비하는 작업입니다. 배포·DB 운영 인프라는 미정입니다.
