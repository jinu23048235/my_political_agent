# 미결정 사항

확정 정책을 반복 질문하지 않습니다. 아래 내용은 결정 전까지 제안 또는 미결정 상태입니다.

## 이번 확인 결과 — 2026-10-18

1. 공식 계정 미참여 대표자 요청도 등록하고 ‘공식 계정 미참여·미전달’을 표시하기로 확정했습니다.
2. 선택형 설문을 MVP에 포함하기로 확정했습니다.

결정은 [확정 정책](../product-decisions.md)에 반영했습니다.

## 해당 기능 설계 전에 확인

- 선택형 설문의 참여 자격, 익명 여부, 단일·복수 선택, 마감, 투표 변경, 결과 공개 방식.
- 미참여 대표자의 공식 계정 참여 후 기존 요청 전달 방식.

- 사진 크기·지원 형식·압축, 공감 취소 등 세부 규칙, 지역 태그 선택 UX.
- 원본에 제시된 시민 요청 유형과 대표자 발신 유형의 화면 적용 및 필수 선택 여부.
- 의원실 업무 관리의 분류·담당자 배정 범위, 공식 자료·후속 현안 연결 방식.
- 행정동 경계·대표자·선거구 데이터 출처, 매칭 검증과 갱신 정책.
- AI 검토 모델·비용 한도·자동 재시도 횟수, 신고 사유·운영 화면 정책.
- 실제 기술 구성·인프라·인증 및 알림 제공자, PWA 세부 범위.
- 사업 운영 조직과 법률·개인정보 책임, 운영비와 수익·후원 모델.

## 재확인이 필요하지 않은 사항

웹 우선·모바일 최적화, 요청 항상 공개, 지역 피드, 글·답글 2,000자 및 사진 4장, 영상 MVP 제외 등은 이미 확정되어 있습니다. 전체 목록은 [확정 정책](../product-decisions.md)을 따릅니다.
