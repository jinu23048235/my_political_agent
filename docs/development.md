# 앱 개발 환경과 현재 구현 범위

## 실행

Node.js 22 이상에서 저장소 루트에서 실행합니다. 정확한 의존성 버전은 `package-lock.json`에 고정합니다.

```bash
npm ci
npm run dev
```

개발 서버는 `http://localhost:3000`에서 실행합니다. 개발 명령만 가상 예시 데이터를 기본 사용합니다. 실제 시민·대표자 정보가 아닙니다. 예시 지역 코드도 실제 행정 코드·선거구 매칭으로 사용하지 않습니다.

```bash
npm test
npm run build
npm run typecheck
npm start
```

운영 실행 기본값은 빈 데이터입니다. `APP_DATA_MODE=sample`을 운영 모드에 지정하면 오류로 거부합니다. 운영 서버에 예시 인물을 실제 인증 계정으로 표시하지 않습니다. `APP_DATA_MODE=empty npm run dev`로 빈 피드도 검토할 수 있습니다.

## 현재 앱

- Next.js App Router·React·TypeScript. `src/app`의 공통 레이아웃, 지역 피드, 글 상세와 대화 흐름, 작성·설정·대표자 메뉴 및 오류 화면.
- 읽기 데이터 어댑터는 현재 예시 또는 빈 데이터만 제공합니다. DB 조회·저장 어댑터와 실제 로그인은 아직 연결하지 않았습니다.
- 로그인 전 작성·설정은 안내 화면이며, 샘플 계정을 실제 세션으로 간주하지 않습니다. 변경 API나 임의의 계정 ID로 활동하는 개발용 API를 공개하지 않습니다.
- 원래의 작성·설문·설정·고정댓글 상호작용 검토는 `prototype/`의 HTML 초안을 유지합니다. Next.js 앱에 모든 기능을 이전한 단계는 아닙니다.
- `/api/health`는 앱 실행 상태만 확인하며 DB·인증 연결 완료를 뜻하지 않습니다.

## DB 적용과 검증

PostgreSQL 17 및 PostGIS 3.5에서 검증했습니다. 대상 DB와 extension 설치 권한을 직접 준비한 뒤 명시적으로 실행합니다. 호스팅·운영 DB는 아직 선정하지 않았습니다.

```bash
DATABASE_URL='postgresql://...' npm run db:migrate
DB_TEST_URL='postgresql://.../neighborhood_test' npm run db:test
```

`.env.example`은 참고용입니다. 마이그레이션 명령에는 셸 환경 변수로 URL을 제공합니다. 실제 비밀번호·키는 저장소에 넣지 않습니다. 테스트 URL은 별도 `*_test` DB여야 하며 운영용 `DATABASE_URL`과 같으면 거부합니다. 테스트 데이터는 트랜잭션으로 롤백합니다. 마이그레이션은 테스트 DB에 유지합니다.

이미 적용된 파일의 체크섬이 달라지면 적용을 거부합니다. 적용 후 변경은 새로운 마이그레이션으로 추가합니다. 마이그레이션 전체는 트랜잭션과 advisory lock으로 보호합니다.
