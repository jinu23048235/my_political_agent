# DB 설계에 반영할 확정 제약

2026-10-18. 이 문서는 확정 정책에 따른 DB 설계 제약입니다. 초기 마이그레이션과 검증 범위는 [DB 스키마](database-schema.md)를 확인합니다.

## 계정과 역할

- 계정에는 현재 활동 역할을 하나만 둡니다. 여러 활성 역할을 연결하거나 화면에서 자유롭게 역할을 바꾸는 구조를 사용하지 않습니다.
- 계정 ID는 역할 변경 전후에도 유지합니다. 역할 변경 이력과 공식 권한·인증 상태를 별도로 기록합니다.
- 시민 역할로 변경할 때는 시민 닉네임 중복 불가 규칙을 적용합니다. 대표자 측 닉네임 중복 허용을 시민 역할로 승계하지 않습니다.
- 공식 계정으로의 신규 인증·복구는 운영자 심사 기준을 적용합니다. 기존 역할을 변경한다고 새 공식 권한을 자동 부여하지 않습니다.
- 기존 게시물·답변은 작성 계정 ID와 작성 당시 소속·공식 작성 기록을 보존합니다. 계정의 현재 역할을 과거 작성 당시 역할로 표시하지 않습니다.
- 권한 회수만으로 시민 역할로 자동 전환한다고 가정하지 않습니다. 공식 권한 회수와 계정 역할 변경을 구분하여 설계합니다.
- 검토 페이지의 참여 상태 선택기는 서로 다른 예시 계정과 인증 상태를 보여주는 도구이며 실제 서비스의 역할 전환 기능이 아닙니다.

## 지역 인증

- 저장할 정보: 계정 ID, 인증 행정동, 인증 일시, 유효기간 등 인증 결과와 권한 판단에 필요한 데이터.
- 사용자의 GPS 원본 좌표는 영속 저장하지 않습니다. 위치 인증 요청의 좌표를 애플리케이션 로그·이벤트·오류 추적에도 남기지 않도록 구현합니다.
- 행정동 경계의 PostGIS 데이터와 사용자의 현재 위치 데이터는 구분합니다. 현재 위치는 행정동·인접 동 경계 500m 판단에 사용한 뒤 보관하지 않습니다.
- 최대 2개 지역·1년 유효기간·30일 변경 간격과 상위 관할 참여 규칙을 서버에서 검증합니다.

## 설문과 본문

- 게시 시 설문 질문·선택지·선택 방식·마감을 확정합니다. 게시 후 이 정의를 수정하는 API를 제공하지 않으며 게시물 수정 요청에 함께 들어와도 변경하지 않습니다.
- 게시물 본문 수정은 허용하고 수정 시각을 기록합니다. 본문 수정과 설문 정의를 별도 갱신 경로로 분리합니다.
- 설문별·계정별 응답은 1개이며, 마감 전 변경은 기존 응답의 원자적 교체로 처리합니다.
- 서버 시각과 현재 지역 인증으로 제출·변경 권한을 판정합니다. 마감 전 집계와 다른 계정의 개인 응답은 반환하지 않습니다.

## 고정댓글

- 글당 고정 댓글 ID를 최대 1개 둡니다. 다른 글의 댓글을 참조할 수 없도록 글·댓글 관계를 검증합니다.
- 원글 작성자 또는 운영자만 고정·해제·교체할 수 있습니다. 댓글 작성자라는 이유만으로 고정 권한을 부여하지 않습니다.
- 고정 대상이 삭제·숨김 상태라면 고정 영역에 노출하지 않도록 콘텐츠 공개 상태와 함께 조회합니다.
- 교체는 하나의 갱신으로 처리하여 동시에 여러 댓글이 고정된 상태를 만들지 않습니다.

## 현재 구현 경계

초기 스키마·마이그레이션을 로컬 PostgreSQL·PostGIS에서 검증했습니다. 서버 세션·쓰기 API와 객체별 권한 검사를 연결했습니다. 실제 소셜 로그인·가입·GPS와 운영자 심사·신고는 다음 단계입니다. 상세 범위는 [서버 API](server-api.md)를 확인합니다. HTML 초안의 검토용 권한 선택기는 서버 인증이 아닙니다.
