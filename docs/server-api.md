# 서버 세션과 저장 API

2026-10-18. 로컬 PostgreSQL·PostGIS와 프로덕션 빌드로 검증했습니다. 실제 소셜 로그인 제공자와 운영 환경은 아직 연결하지 않았습니다.

## 인증과 공통 검사

세션은 무작위 32바이트 토큰의 SHA-256 해시만 DB에 저장합니다. 쿠키는 HttpOnly·SameSite=Lax·호스트 전용이며 운영에서는 Secure입니다. 현재 구현의 세션 만료는 24시간입니다. 이는 조정 가능한 구현 설정이며 별도의 확정 제품 정책은 아닙니다.

`issueVerifiedSession`은 서버 내부 함수입니다. 제공자의 신원을 검증하고 계정을 확인한 후에만 호출해야 합니다. 호출자가 보낸 계정 ID로 로그인하는 공개 API는 없습니다. 소셜 로그인 콜백·신규 가입·소셜 계정 연결은 미구현입니다. 테스트는 외부 신원 검증을 우회하는 공개 경로를 추가하지 않고 내부 함수로 테스트 세션을 만듭니다.

매 요청에서 유효한 세션과 현재 계정을 조회합니다. 쓰기는 계정 행을 잠근 뒤 현재 역할·정지 상태·지역 인증·공식 위임·임기·재직 확인을 재검사합니다. 계정 역할 변경·정지 시 기존 세션과 공식 권한을 회수합니다. 퇴직 확인 후 재직 응답만 바꿔도 권한이 복구되지는 않습니다.

변경 요청은 `Origin`을 `APP_ORIGIN`과 비교합니다. 설정이 없을 때는 요청 URL의 origin을 사용합니다. 운영에서는 정확한 HTTPS 서비스 주소를 설정해야 합니다. JSON 요청은 64KiB까지 받고 허용 필드만 처리합니다. 오류에 SQL·연결 정보·개인 응답을 포함하지 않으며 응답은 `private, no-store`입니다.

## 경로

| 경로 | 동작 |
| --- | --- |
| `GET /api/session` | 현재 로그인 계정 또는 null |
| `POST /api/logout` | 현재 세션 회수·쿠키 만료 |
| `GET, POST /api/posts` | 지역별 공개 목록·글 작성 |
| `GET, PATCH, DELETE /api/posts/:id` | 공개 상세·본인 수정·본인/운영자 삭제 |
| `POST /api/posts/:id/replies` | 같은 글의 부모를 지정하여 답글 작성 |
| `PATCH, DELETE /api/replies/:id` | 본인 수정·본인/운영자 삭제 |
| `PUT /api/posts/:id/pin` | 원글 작성자/운영자의 고정·해제·교체 |
| `POST /api/posts/:id/empathy` | 원글 지역 인증 시민의 중복 없는 공감 |
| `PATCH /api/posts/:id/recipients/:representativeId` | 해당 공식 계정의 직접 접수 확인·답변 보류 |
| `GET /api/representatives?region=...` | 해당 지역과 상위 관할의 대표자·참여 여부 |
| `GET /api/surveys/:id` | 공개 설문 정의·본인 응답·마감 후 집계 |
| `PUT /api/surveys/:id/response` | 현재 지역 인증 시민의 설문 응답 교체 |
| `GET, PATCH /api/settings` | 본인 닉네임·알림 설정 |
| `POST /api/account/employment` | 직원 재직 확인 또는 명시적 확인 후 공식 권한 회수 |

글 목록은 현재 최대 40개이며 무한 스크롤은 미구현입니다. 답글은 대화 한 흐름당 100개를 조회하고 `conversation`·`cursor`로 다음 범위를 탐색합니다. 대화 깊이 제한은 없습니다. 고정 답글은 중복 표시하지 않습니다.

글 작성은 `regionCode, kind, body, link`를 받습니다. 시민 요청은 `recipientIds`가 필요하며 여러 대표자를 지정할 수 있습니다. 공식 의견 요청에는 `survey: {question, choices, mode, closesAt}`를 추가할 수 있습니다. `closesAt`은 시간대가 포함된 ISO 시각이며 화면 입력은 한국 시간입니다. 응답의 `selectedIndexes`는 **0부터 시작**하는 선택지 인덱스입니다. 게시물 PATCH는 `body, link`만 받으므로 설문 변경을 함께 보내면 전체 요청을 거부합니다.

공식 답변 등록은 그 대표자의 상태만 답변 완료로 바꾸고 직접 접수 확인 시각을 만들지 않습니다. 마지막 공개 공식 답변 삭제는 해당 대표자만 보류로 바꿉니다. 공식 답변이 있는 삭제 요청은 본문을 비우고 대화를 보존합니다.

설문 GET은 마감 전 집계를 반환하지 않습니다. 로그인한 본인의 선택만 반환하며, 마감 후 비로그인 사용자에게도 집계를 제공합니다. 개인별 응답 목록 API는 없습니다.

## 현재 경계

- OAuth·가입·역할 변경 UI·운영자 공식 심사·실제 GPS 인증·행정 경계 및 선거구 자료 수집은 미구현입니다. 공식 권한을 임의로 부여하는 API도 없습니다.
- 실제 사진 저장소가 없어 업로드 입력을 제공하지 않으며 비어 있지 않은 사진 payload는 거부합니다.
- 알림 설정은 저장되지만 서비스 내 알림 생성·푸시 발송은 아직 연결하지 않았습니다. 팔로우 생성/해제 UI도 후속 작업입니다.
- 공감 취소 정책은 미결정이므로 현재 API에는 취소 동작이 없습니다.
- 공식 계정에 같은 지역의 복수 대표자 위임이 동시에 유효하면 작성할 소속을 추측하지 않고 거부합니다. 복수 소속 운영이 필요하면 선택 정책을 확인해야 합니다.
- DB는 서버 내부에서만 접근합니다. 공개 DB 접속·브라우저의 직접 테이블 접근은 제공하지 않습니다. 운영용 DB 역할·최소 권한·비밀 관리·TLS·호스팅은 운영 환경 구성 시 적용해야 합니다. 현재 로컬 검증은 신뢰하는 임시 DB 계정으로 수행했습니다.
