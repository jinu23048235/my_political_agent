# 화면 초안 v0.4

2026-10-18 작성. **검토용 제안이며 디자인과 신규 정책을 확정한 문서가 아닙니다.**

## 열어보기

실행 파일 묶음을 풀고 `prototype` 폴더 안의 [index.html](../prototype/index.html)을 브라우저에서 엽니다. 함께 있는 설문 스크립트 파일도 유지합니다. 설치·외부 연결 없이 동작합니다. 검토용 참여 상태·너비 선택기는 [별도 검토 페이지](../prototype/review.html)로 옮겼습니다. 서비스 화면에는 표시하지 않습니다. 새로고침하면 입력 내용이 초기화됩니다.

## 화면 구성 제안

| 화면 | 핵심 구성 |
| --- | --- |
| 지역 피드 | 시·구·동 경로 탐색, 하위 지역 글 포함, 최신순·공감순, 긴 글 더 보기, 공식 답변 예고 |
| 글 상세·답글 | 원글, 대표자별 요청 상태, 공식 작성자의 소속과 본인·위임 직원 인증, 고정댓글 1개, 대화 흐름을 펼치는 답글 |
| 글 작성 | 지역 선택, 동네 이야기·시민 요청 구분, 본문, 사진, 외부 링크, 요청 대표자 복수 선택, 공개 안내 |
| 설정 | 닉네임, 지역 인증 관리 진입점, 요청 알림 유형별 설정, 팔로우 대표자별 새 게시물 알림, 웹 푸시 관리 진입점 |

데스크톱은 왼쪽 메뉴·가운데 피드·오른쪽 지역 대표자 안내를 배치합니다. 모바일에서는 가운데 콘텐츠와 하단 지역·글쓰기·대표자·설정 메뉴를 중심으로 보여줍니다. 중간 너비에서는 오른쪽 안내를 접습니다.

기본 피드는 마포구입니다. 예시 시민은 성산1동 인증 상태로, 마포구 글에는 참여할 수 있지만 망원1동 글은 읽기만 할 수 있습니다. 성산1동 글과 망원1동 글이 상위 피드에 함께 표시되어도 원글 지역 기준으로 권한을 판단합니다.

## 반영한 확정 정책

- 글·답글 모두 2,000자, 사진 최대 4장, 외부 링크. 영상 업로드 없음.
- 요청은 항상 공개. 대표자를 여러 명 선택 가능.
- 플랫폼 등록·의원실 접수 확인·공식 답변 상태를 대표자별로 표시.
- 공식 계정 미참여 대표자는 미참여·미전달로 표시.
- 답글은 일정한 폭으로 표시하고 해당 답글의 다음 대화를 펼침. 깊이에 제한을 두지 않는 데이터 구조.
- 공식 작성자의 이름·소속·본인 또는 위임 직원 인증 표시.
- 지역 인증 만료·로그아웃·관할 밖 참여 제한. 상태 선택기는 서비스 화면에서 제거하고 별도 검토 페이지에만 제공.
- 원글 지역 인증을 기준으로 공감 제한. 공감 취소는 미결정 상태로 안내.
- 게시물 수정 날짜·시간 표시. 공식 답변이 있는 요청 삭제 시 본문을 삭제 표시로 바꾸고 답변 보존.
- 신고는 로그인 여부로 제한하고, 실제 신고 처리 대신 후속 구현 안내.

## 반영한 화면 피드백

- 현재 녹색 계열은 사용자 확인을 받았으며 서비스명·로고 확정 후 변경할 수 있습니다.
- 검토용 상단 도구·중복 서비스명 헤더·영문 부제·초안 배지·반복 안내·참여 가능 표시를 제거했습니다.
- 피드의 중복 글쓰기 입력 영역을 제거하고 기존 작성 버튼·하단 글쓰기 탭을 유지했습니다.
- 상세·작성 화면에는 지역 피드로 돌아가는 간단한 헤더만 남겼습니다.
- 하단 맨 오른쪽 및 데스크톱 메뉴에 설정을 추가했습니다.

고정댓글은 원글 작성자·운영자가 각 답글의 메뉴에서 고정·해제·교체합니다. 고정된 댓글은 전체 대화 상단에 한 번만 표시하며, 깊은 답글이라면 답글 상대와 이어진 대화 진입점을 함께 제공합니다. 검토 도구의 운영자 계정은 다른 예시 계정과 별개이며 실제 계정의 역할 전환 기능이 아닙니다.

## 추가 검토 대상

- 3열 데스크톱·1열 모바일 배치의 세부 조정.
- 동네 이야기와 시민 요청을 같은 작성 화면에서 전환.
- 시민 요청 세부 유형, 사진 규격과 압축, 지역 태그 선택의 최종 UX는 미확정.
- 설문 세부 정책이 확정되어 작성·참여·응답 변경·마감 후 공개 결과를 연결했습니다. [설문 화면과 검증](survey-screen-draft.md)을 참고합니다.

## 구현 및 검증 범위

프레임워크·서버·DB 없이 실행하는 HTML 프로토타입입니다. 예시 인물과 글은 가상 데이터입니다. 별도 검토 페이지에서 권한 상태를 모의하며 실제 보안 통제가 아닙니다. 카카오·네이버·구글 로그인, GPS, 실대표자 조회, 알림·팔로우, 운영자 인증·신고 처리, AI 검토, 의원실 관리, 답글 수정·삭제는 후속 구현 범위입니다. 실제 앱 기술은 Next.js·TypeScript + PostgreSQL·PostGIS로 확정했으며 운영 인프라는 미정입니다. 설정의 닉네임과 알림 변경은 현재 화면 메모리에만 저장하며, 닉네임 중복 검사도 예시 데이터 범위입니다. 지역 인증·웹 푸시 버튼은 후속 화면의 진입점이며 아직 실제 GPS·알림 권한을 연결하지 않았습니다.

Chromium에서 화면 전환, 대화 흐름 펼치기, 지역별 참여 및 공감 제한, 새 요청·답글 작성, 글자 수 제한, HTML 문자 표시, 요청 삭제 후 공식 답변 보존을 검증했습니다. 320·390·768·1024·1440px에서 가로 넘침과 JavaScript 오류가 없음을 확인했습니다. 사진 5장 선택 거부·4장 미리보기 및 삭제, http·https 이외 링크 거부도 확인했습니다.

설정 저장 후 재진입 시 닉네임·알림값 유지, 로그인 전 개인 설정 제한, 설정 탭의 선택 표시, 검토 요소 제거도 검증했습니다.
