- 지역 피드·글 상세와 답글·글 작성의 실행 가능한 HTML 화면 초안 v0.4을 작성했습니다.
- Chromium에서 주요 화면 동작과 320~1440px 반응형 레이아웃을 검증했습니다.
- 화면 초안·스크린샷은 로컬 `prototype/`에 있습니다. 상세 범위는 [화면 초안](screen-draft.md)을 확인합니다.
- 사용자 피드백으로 중복 헤더·안내·검토 표시·피드 글쓰기 입력 영역을 제거했습니다.
- 모바일 하단 맨 오른쪽과 데스크톱 메뉴에 설정을 추가하고 닉네임·알림 변경을 모의 구현했습니다.
- 녹색 계열은 현재 방향으로 확인받았으며, 서비스명·로고 확정 후 변경 가능합니다.
- 변경 사항은 GitHub 초안 PR #1에서 관리합니다.

- 설문 세부 정책 3건을 확인하고 작성·참여·응답 변경·자동 마감·공개 결과 화면을 연결했습니다.
- 설문 모델 및 브라우저 검증을 수행했습니다. 상세 범위는 [설문 화면](survey-screen-draft.md)을 확인합니다.

- 앱 기술 구성은 Next.js·TypeScript + PostgreSQL·PostGIS로 확정했습니다.
- 단일 활동 역할과 역할 변경, GPS 원본 미저장, 게시된 설문 수정 불가·본문 수정 허용 정책을 추가했습니다.
- [DB 설계 제약](data-design-constraints.md)에 계정·위치·설문 저장 규칙을 정리했습니다.
