# 개발 진행 현황

기준일: 2026-10-18 (한국 시간).

## 완료

- 첨부 원본 3개·확정 정책·미결정 사항·인계를 구분하여 정리했습니다.
- HTML 화면 초안 v0.4에 피드·대화·작성·설정·설문·고정댓글과 사용자 피드백을 반영했습니다.
- Next.js·TypeScript 반응형 앱과 PostgreSQL·PostGIS 마이그레이션을 구성했습니다.
- DB 기반 피드·글 상세·깊은 대화 조회와 작성·수정·삭제·공감·고정댓글 API를 연결했습니다.
- 대표자별 직접 접수 확인·답변 상태, 마지막 공식 답변 삭제 시 해당 대표자 보류 전환을 구현했습니다.
- 설문 생성·응답 교체·마감 후 공개 집계와 닉네임·알림 설정 저장을 연결했습니다.
- 해시 기반 서버 세션·현재 역할/권한 검사·직원 재직 확인·권한 회수·역할 변경 시 기존 세션 무효화를 구현했습니다.
- 로컬 PostgreSQL 17.11·PostGIS 3.5.2에서 마이그레이션·기존 제약·실제 HTTP 통합 검증을 수행했습니다. 운영 DB가 아닙니다.
- 정책 단위 검사 3개·DB 제약·빌드·타입 검사·HTTP 통합 검증 84개와 Chromium의 작성/답글/고정/설문/설정 및 320~1440px 화면 검증을 통과했습니다. 이번 변경의 원격 CI 결과는 GitHub 실행 상태로 확인합니다.

## 현재 범위

화면에서 서버 저장까지 연결한 단계입니다. 실제 소셜 로그인·가입과 외부 운영 환경은 미연결입니다. 계정을 ID로 지정하여 로그인하는 공개 테스트 API는 없으며 검증은 격리된 테스트 계정과 서버 내부 세션 발급 함수로 수행합니다. HTML 초안의 모든 기능이 실제 앱으로 이전된 것은 아닙니다.

정책과 변경 기록은 GitHub 초안 PR #1에서 관리합니다. [개발 환경](development.md), [서버 API](server-api.md), [DB 스키마](database-schema.md), [미결정 사항](open-questions.md)을 확인합니다.

## 다음 작업

1. 카카오·네이버·구글 제공자 등록·콜백·가입·계정 연결. 제공자 설정과 서비스 주소가 필요합니다.
2. 실제 행정 경계·대표자·선거구 데이터 출처 확인과 GPS 인증, 30일 지역 변경 제한.
3. 파일 저장·운영자 공식 심사·신고와 AI 검토·서비스 내 알림 및 푸시 발송.
4. 운영 DB 최소 권한·비밀 관리·호스팅과 배포 설정.

추가 정책 확인 없이 이번 서버 저장 단계는 진행할 수 있었습니다. 사진 규격·공감 취소 등 미결정 세부 사항은 해당 기능 구현 전에 확인합니다. 서비스 명칭·로고는 잠정 상태이며 녹색 계열도 이후 변경 가능합니다.
