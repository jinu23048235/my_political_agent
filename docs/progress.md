# 개발 진행 현황

기준일: 2026-10-18 (한국 시간).

## 완료

- 첨부 원본·결정 기록·인계를 정리하고 확정 정책과 미결정 사항을 구분했습니다.
- HTML 화면 초안 v0.4: 지역 피드·상세·대화·글 작성·설정·설문·고정댓글. 사용자 피드백과 정책을 반영하고 브라우저 검증을 마쳤습니다.
- Next.js·TypeScript 앱을 초기 구성했습니다. 공통 메뉴·지역 피드·글 상세·대화 읽기·오류 화면과 로그인 전 작성/설정 안내를 이전했습니다.
- PostgreSQL·PostGIS 초기 마이그레이션과 체크섬/트랜잭션 기반 적용 명령, 별도 테스트 DB 검증을 작성했습니다.
- 실제 PostgreSQL 17.11·PostGIS 3.5.2에서 주요 제약과 마이그레이션 재실행을 검증했습니다. 서버는 로컬 임시 검증용이며 운영 DB가 아닙니다.
- 프로덕션 빌드·타입 검사·지역 권한/예시 데이터 분리 테스트와 320~1440px Next.js 화면 검증을 수행했습니다.
- GitHub Actions에 앱·DB 검사 구성을 추가했습니다. 원격 CI 성공 여부는 실제 실행 결과로 따로 확인해야 합니다.

## 현재 범위

실행 가능한 실제 앱의 기본 구조와 DB 스키마가 준비된 단계입니다. Next.js 데이터 어댑터는 개발용 예시 또는 빈 데이터이며 아직 DB와 연결하지 않았습니다. 기존 HTML 초안의 모든 상호작용을 Next.js로 이전한 것은 아닙니다.

정책과 변경 기록은 GitHub 초안 PR #1에서 관리합니다. [개발 실행 방법](development.md), [DB 스키마](database-schema.md), [DB 설계 제약](data-design-constraints.md)을 확인합니다.

1. 소셜 로그인 제공자 설정과 서버 세션·현재 역할·공식 권한 검증.
2. DB 조회·저장 연결 및 글·답글·설문·고정댓글 API.
3. 실제 GPS 인증, 행정 경계·대표자 데이터 소스 검증.
4. 의원실 처리 상태·공식 권한 회수·신고·알림 작업 연결.

배포·DB 운영 서비스 선정과 외부 운영 환경 생성은 아직 하지 않았습니다. 카카오·네이버·구글 실제 인증, 파일 저장, 웹 푸시, 운영자 심사·신고·AI 검토와 법률·개인정보 운영 검토도 미완료입니다.
